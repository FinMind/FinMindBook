# FinMindBook 5 - 打造台股爬蟲與自動化資料工程

本章從零開始打造台股資料工程，從 Python 環境管理、撰寫爬蟲、部署 MySQL 資料庫、上傳資料，
到引入 RabbitMQ + Celery 的任務佇列做分散式爬蟲，最後用排程器將整個流程自動化。

## 內容
    5.1 Python 環境管理（pipenv、poetry、uv）
    5.2 撰寫台股、上櫃、期貨爬蟲
    5.3 用 docker 部署 MySQL 資料庫
    5.4 將爬蟲資料上傳資料庫
    5.5 RabbitMQ + Celery 分散式爬蟲
    5.6 用排程器自動化爬蟲
